# Sample Data

This directory contains representative datasets used for development, testing, and demonstration of the SIH26023 AI Geological & Mining Reporting Platform.

## Categories

01_Production
- Annual coal production
- Month-wise production

02_Subsidiary_Production
- Production reports of Coal India subsidiaries

03_Geological_Resources
- Geological resource tables
- Grade-wise resources
- Depth-wise resources

04_CMPDI_Documents
- CMPDI annual reports

05_Parliamentary_QA
- Starred and Unstarred Parliamentary Questions

06_Ministry_of_Coal_Reports
- Ministry reports
- Exploration
- Marketing
- R&D

07_Coal_Quality_Validation
- Coal quality reports

08_Official_CCO_Excel
- Official production spreadsheets

09_Mine_Master
- Mine master datasets

10_Historical_Data
- Historical mining reports

These datasets are used only for development and demonstration.
